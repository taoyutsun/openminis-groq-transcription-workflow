# 測試範圍

本文件區分原始私人版經驗、本公開版離線檢查及尚未完成的裝置／雲端驗證。

## 已設計的離線回歸測試

v0.2.0：2026-10-02，Windows 與 Ubuntu WSL 的 Python 環境各通過全部 39 項測試，沒有略過項目。保留 v0.1.0 的 19 項回歸情境並新增模型橋接及分層摘要測試；兩個環境都有 FFmpeg／ffprobe，合成 WAV → M4A 解碼及模擬 API 的端到端流程均通過。未進行真實 API 呼叫或手機操作。

在專案根目錄執行：

```sh
python3 -B -m unittest discover -s tests -v
```

測試使用臨時檔案、假金鑰、模擬 Groq 回應；不連外、不使用作者錄音、不產生付費 API 呼叫。

- 金鑰未出現在子程序參數，HTTP 失敗與例外不顯示假金鑰。
- HTTP 失敗不顯示回應正文；禁止重新導向。
- `--list`／`--dry-run` 不呼叫 API、不建立輸出，預設一份、全部及指定多份的選取範圍。
- 子資料夾須明確加 `--recursive`，排除輸出資料夾。
- 原始 prompt 保留，審慎模式只增加通用提示。
- 逐字稿同大小但內容改變時，摘要快取失效。
- 壞掉的片段 JSON 重做、完整片段續跑、不完整轉錄不進入摘要。
- 新摘要失敗時保留原摘要。
- 完成後重跑略過；摘要設定改變時不重傳音訊。
- 有 FFmpeg／ffprobe 的 Linux 環境可測試自製 WAV 及轉成的 M4A，驗證解碼與轉錄／摘要的模擬端到端流程。沒有工具時這部分會明確標示略過。
- Minis 摘要的精確模型選擇、同名供應商辨識、未授權／非文字模型在上傳前停止。
- 逾時、不相容 JSON、空摘要、模型身分不符、報告為截斷／中斷或用完輸出預算時不得保存完成摘要。
- 暫存檔正常離開時清除；模型及 prompt 改變使摘要快取失效。
- Groq → Minis 摘要切換沿用同一組 SRT／逐字稿、不重傳音訊；已完成 Minis 摘要重跑略過，摘要單獨執行不需 Groq Key。
- Groq 長摘要切分保持完整文字、413 自適應二分、完成節點續跑，以及 Retry-After 不裁成 90 秒。
- 官方 Android 舊式模型清單格式明確停止，不放寬成功驗證；可由使用者明確選擇 Groq 模式。

## 原始私人版紀錄

作者在 iPhone 上曾試跑約 25 分 40 秒的錄音，產生 SRT、逐字稿及摘要。修正語言設定後 SRT 保留英文原語。當時的程式、摘要 prompt 與本公開版並不完全相同。

後續私人 iPhone workflow 以約 81 分 38 秒的錄音完成 21 個轉錄片段。Groq 120B 摘要曾碰到 8,000 TPM 與 429／413，改用分層摘要後完成。其後將 GPT-6-Sol 加入 App 可調用模型清單，透過 `minis-model-use` 與 App 已登入的 Codex OAuth，單次處理約 41,765 個輸入 token 的完整逐字稿並完成摘要；沒有匯出 OAuth 憑證，也沒有重轉 SRT。

上述是作者提供的私人開發對話與使用經驗，不是 v0.2.0 公開版測試程式可重現的真機驗證。私人版通過的 5 項離線測試也不等於公開版的完整測試覆蓋。模型能成功處理該份資料，不代表所有帳戶用量政策、更長錄音或 Android 都相同。

## 待完成的手機與雲端驗證

1. iPhone「語音備忘錄」將不含私人資訊的短錄音分享成 M4A，存至輸入資料夾。
2. 公開版五支程式另放 `/var/minis/shared/錄音轉錄工具/`，保留現有私人版。掛載來源後執行 `--list`、`--dry-run`，測試輸出另外指定 `/var/minis/shared/錄音公開版測試/`。
3. 用自己的 Key 正式執行最終版本，確認 SRT 原語、繁中摘要及檔案取用。
4. 同設定重跑，確認不再呼叫轉錄／摘要 API。
5. 切換摘要模式，確認音訊不重傳、舊摘要保留。
6. 在裝置可控條件下中斷並重跑，核對片段與摘要進度。
7. Android 選取可存取的本機錄音資料夾，或先匯出至專用資料夾，重複上述流程。

Minis 預設模式需先確認 App 可提供支援的 JSON 封裝及完成狀態；不同版本的 Android 格式不相容時，用明確的 `--summary-backend groq`。iPhone 公開版還應驗證模型允許清單與實際 stop_reason／usage、正常 OAuth 更新、長摘要輸出預算與中斷重跑。本次沒有操作手機、重新上傳私人錄音或產生雲端用量。

不要以 Linux 上通過的離線測試宣稱 iOS／Android 真機或雲端長錄音已驗證。M4A 以外格式、多人說話與多語頻繁切換也需要自己的音檔抽查。
